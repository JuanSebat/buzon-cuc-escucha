# Buzón CUC Escucha

## Universidad de la Costa

Micrositio web front-end para la asignatura **Buenas Prácticas de Desarrollo
de Software**.

## Objetivo

Crear un buzón digital donde los estudiantes puedan registrar sugerencias
relacionadas con su experiencia universitaria.

## Estructura

```text
buzon-cuc-escucha/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
├── img/
└── README.md
```

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Netlify

## Identidad visual

Referencia al manual de marca suministrado de la Universidad de la Costa.

- Rojo CUC: `#A3161A`
- Gris: `#595959`
- Blanco: `#FFFFFF`
- Tipografía: Red Hat Display

## Primera versión

El formulario inicial contiene nombre completo, correo institucional,
sugerencia y botón de envío. Es una implementación únicamente front-end.
